# Deviations log

Every place where the delivered code differed from the spec, the spec was wrong, or a gate caught a
problem worth telling. Reviewers append entries on the PR branch (spec §8.2). This file feeds the
public case study, so failures are recorded as plainly as successes.

Format (spec §8.4). Ids are cluster-scoped so concurrent reviewers never clash.

| Id | AC / D id | What was wrong | Caught by | Severity | Resolution | PR |
